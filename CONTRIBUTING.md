# Contributing to 4-noks Custom Component

Contributions are welcome!

## Setting Up Development

1. Fork and clone the repository.
2. Run `scripts/setup` to install all dependencies.
3. Use `scripts/lint` to run code checks with Ruff.
4. Use `scripts/develop` to launch a test instance of Home Assistant configured to load this custom component.

## Testing

Run tests with:
```bash
pytest
```
